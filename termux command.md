# Termux Command Prompt

---

###  termux-setup-storage
Memberikan aplikasi termux akses ke folder-folder didalam perangkat. 

Berfungsi untuk memindahkan file yang tertutup rapat didalam Termux ke folder didalam perangkat supaya aplikasi seperti gallery atau aplikasi pembaca dokumen office dapat membaca atau mengakses file-file yang telah dibuat atau diunduh didalam Termux.
